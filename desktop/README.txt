Free HD Download / 无水印下载 1.2.2

Windows 10/11 x64. Extract the entire ZIP, then run FreeHDDownload.exe.
Keep the app and runtime folders next to the EXE. No Java installation required.

将整个 ZIP 解压后，双击 FreeHDDownload.exe；不要单独移动 EXE。
粘贴抖音、小红书或 B站分享链接，等待解析，选择目录与画质后保存。
文章支持复制和 UTF-8 TXT；图集可批量保存。
普通链接在电脑本地解析和下载；无网址的抖音口令使用公共转换服务。
B站高清：点击“B站登录”，使用手机B站扫码确认，应用会重新获取账号可用画质。
登录状态保留在本机应用数据目录，可点击“B站已登录”退出。
小红书图片使用原图源，不使用带平台水印的H5展示图。
平台返回的画质、访问限制、嵌入画面的水印均受原内容影响。

Paste a Douyin, Xiaohongshu or Bilibili share link. Choose a destination
and an available quality, then save the video, images or article text.
URL-less Douyin commands use a public third-party token conversion service.
For Bilibili HD, click B站登录 and scan with the Bilibili mobile app.
The app retains the session locally. Click B站已登录 to sign out.
Xiaohongshu images use original sources instead of H5 display images.
Embedded watermarks are not removed. Available resolution depends on the source.

History: %LOCALAPPDATA%\FreeHDDownload\history.json
Clearing history does not delete downloaded files.
Unsigned builds may trigger Windows SmartScreen.
