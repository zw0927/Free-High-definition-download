# 无水印下载：Android 历史说明

原生 Java Android 应用，支持 Android 8.0 及以上。新版安装包：`release/无水印下载-1.2.1.apk`。沿用首版包名 `cn.dousave.app` 和本地签名密钥，可覆盖升级。

## 1.2.1 更新

- 复制文案、保存文字 TXT 按钮仅在解析成功后随结果显示；清空、修改输入或重新解析时隐藏。未解析的分享文案不会作为作品正文导出。
- 点击输入区“清空”或“清空记录”，同时移除已结束的下载提示及其持久化状态，避免“已保存到相册”在回到应用时重新出现。正在进行的下载保留进度和取消按钮。
- 新增抖音文章口令识别，包括用户提供的 `︽︽b20eVzrttZitb9ŠŠ`。口令转换后从抖音取得文章标题和完整 Markdown 正文，可复制及保存 UTF-8 TXT；文章配图可保存到相册。文章不会被误当成视频。
- 该用户样例已用同一 Java 核心从完整口令解析成功：作品 `7708756233431436544`，“新青年思辨”的《“何不食肉糜”：为什么总有人站着说话不腰疼？》，返回正文1616个 Java 字符，无视频和配图。无完整正文时会报错，不以摘要或分享文案冒充全文。
- 无链接口令依赖第三方公共服务 `parse-api.sokoko.org` 转换为作品编号，仅发送提取出的口令，不发送整段文案、平台 Cookie 或账号。取得编号后直接请求抖音正文。服务不可用时会提示重试或改用作品网页链接；普通分享链接仍直接解析。

本轮核心回归、真实口令解析、Android 编译和签名检查通过；尚未连接安卓设备验证 UI、安装及系统保存流程。TXT 保留原始 Markdown 的段落、标题、强调符号和图片链接，不生成 MP4。

## 1.2.0 更新

- 文案可选择、复制或保存成 UTF-8 TXT；TXT 通过系统文件选择器指定位置，不写应用缓存。
- 抖音、小红书图文作品可批量保存图片；视频作品可单独保存封面。支持 JPEG、PNG、WebP，保存时检测真实格式。
- 粘贴和清空按钮增加可见边框与间距；最近下载增加清空记录按钮，只清记录，不删除相册内容。
- 视频直接写入公共相册待完成文件。B站合流轨道同样存于公共存储的待完成文件，任务结束后删除，最终只保留相册成片。不产生应用缓存视频副本；启动下载服务时清理旧版本的三个已知缓存文件。
- 新相册目录为 `Movies/无水印下载`，图片为 `Pictures/无水印下载`，旧版已保存的 `Movies/DouSave` 内容保留。
- 修复小红书 `xhslink.cn` 分享域名、HTTPS 跳转、登录重定向路径及手机页面 `noteData.data.noteData` 结构。用户给出的“新闻联播云电脑关机”已用同一 Java 核心实际下载并完整解码：1920×1080、45.58秒、有声、12545793字节。
- 用户 B站样例的左上角账号和 bilibili 标识存在于平台播放流的图像像素中。应用未添加该标识，也无法通过换下载地址恢复无标识原片；不进行裁剪或遮盖。

批量图片中途失败时已完成的图片保留，其余提示失败。平台限制、付费、DRM 和作者嵌入画面的标识不由本工具消除。本轮仍无安卓设备，公共相册写入及 Android 合流尚未真机实测。

## 使用

1. 打开“无水印下载”，粘贴完整分享文案或链接；停止输入约 0.9 秒后自动解析，也可点击解析按钮重试。
2. 支持抖音、小红书和 B站普通视频；也可通过系统文字分享菜单发送链接到本应用。
3. 解析完成后查看作品、选择画质，再点击下载。
4. 下载成功后在相册的“无水印下载”文件夹查看，也可点击最近下载记录打开。

应用不加载官方 WebView，也不要求在内嵌页面完成验证码。普通链接使用平台页面和接口；没有网址的抖音口令先通过上述第三方服务转换编号，再请求抖音内容。平台及口令服务仍可能因网络、作品状态或访问策略拒绝请求，不能承诺所有作品永远免验证可下载。解析最多等待 60 秒，之后可重试。

## 各平台

| 平台 | 实现 | 当前验证情况 |
| --- | --- | --- |
| 抖音 | 匿名 ttwid 会话、a_bogus 签名，读取多档播放源；支持图文、文章正文及口令转换 | 视频样例下载并解码：1080×1920，17.23 秒，507913 字节；本轮文章口令实际返回1616字符正文 |
| 小红书 | 保留完整分享参数，读取电脑及手机 INITIAL_STATE 和 originVideoKey 原片地址 | 用户提供的 xhslink.cn 视频已下载并完整解码；图文结构通过合成样本 |
| B站 | 支持 BV、av、b23.tv、分P；配对 H.264 视频和 AAC 音频，使用 Android MediaExtractor/MediaMuxer 合并 | 真实视频与音轨均已下载，Windows 合流和解码通过；Android 合流仍待真机验证 |

小红书请使用 App 的“分享→复制链接”完整文案，不要删除 `xsec_token`。没有原片地址时会报错，不使用可能带平台角标的播放流。原片分辨率以下载后的视频为准。

B站本版不提供登录，画质由平台对匿名访问者返回的实际轨道决定，通常受限于较低画质。仅支持普通视频，不支持会员、付费、DRM 或登录后才能观看的内容。没有音轨的 DASH 响应会被拒绝，避免保存无声成片。

“无水印”指选取平台提供的无水印播放源或原片；不裁剪、不模糊、不重编码，不移除作者嵌入画面的内容，也不把低清视频放大冒充高清。

## 验证边界

**本轮没有连接安卓手机，因此尚未实测 APK 安装启动、手机网络下的解析、Android 系统合流、前台通知及相册保存。** Windows 同一 Java 核心的网络实测不能代替安卓真机验证。完整记录见 `VALIDATION.md`。

## 构建

需要 Windows PowerShell、JDK 17 和网络，默认 JDK 位于 `C:\Program Files\Java\jdk-17`。

```powershell
cd E:\temp\DouSave
.\tools\setup.ps1
.\tests\run.ps1
.\build.ps1
```

`setup.ps1` 从 Google 官方下载 Android 35 SDK 及构建工具到 `.tools`。测试 JSON 库仅用于本地测试，APK 使用 Android 内置 JSON。构建脚本默认删除中间 `build` 目录；`-KeepBuild` 可保留用于排查问题。

`signing/dousave.keystore` 是后续覆盖升级所需的个人构建密钥，请私下保留。脚本固定口令便于本机复现，不应公开分发密钥。

## 参考与文件

- `MainActivity.java`：原生界面、自动解析、画质、分享接收和下载记录。
- `ShareLink.java`、`VideoInfo.java`、`VideoResolver.java`：三平台链接、元数据和媒体源。
- `HttpClient.java`、`NetworkPolicy.java`、`DouyinSigner.java`：会话、网络域名检查及签名。
- `DownloadService.java`、`MediaMux.java`：前台下载、取消、备用源、轨道校验、合并及保存。
- `GalleryItem.java`：公共相册待完成文件、发布、格式识别和残留恢复清理。
- `tests/`：合成样本回归测试；`ResolveProbe.java` 可独立执行真实链接探测及可选下载。
- `assets/THIRD_PARTY_NOTICES.txt`、`assets/licenses/Apache-2.0.txt`：第三方说明及许可证，随 APK 打包。
- `CHANGES.md`：本轮修改文件清单。
