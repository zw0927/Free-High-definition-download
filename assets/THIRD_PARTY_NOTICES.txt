The Java port, SM3 implementation and Android integration were added and
modified for this application in November 2026. The original Python code
is not bundled. The full license is included at licenses/Apache-2.0.txt.

Parser behavior and public platform data layouts were researched using:
https://github.com/yt-dlp/yt-dlp
https://github.com/gdSHAY/douyin-wm-downloader
No code from the latter repository, which has no reuse license, is bundled.
No yt-dlp runtime is bundled. Android media APIs perform local muxing.

Douyin share-command service and article data fields were researched using:
https://github.com/sokoko-org/nonebot-plugin-parser-lite/pull/411
https://github.com/sokoko-org/nonebot-plugin-parser-lite/pull/413
No Python source or runtime from these pull requests is bundled.
URL-less Douyin commands send only their extracted public token to
https://parse-api.sokoko.org/api/douyin/resolve to obtain an item ID.
Article content is then fetched from Douyin, as with ordinary links.
The public service is operated by a third party and may be unavailable.
